# 学术派

一个基于 Pi 代理的 Windows 桌面工作台。对外名称统一为「学术派」，使用用户提供的深蓝底、金色火炬与月桂、白色书页徽章；窗口标题、回复头像和署名、状态提示、设置与默认助手身份保持一致。界面保留包豪斯几何构成、细分隔线和少量三原色；蓝色表示主要操作与选中状态，红色用于停止和错误。跟随系统浅色、深色和高对比度设置，并支持减少动画。

产品英文名为 Insight。Windows 用户数据位于 `%APPDATA%\Insight`；其他系统使用 Electron 为该产品解析的用户数据目录。首次启动迁移旧版个人数据并保留原目录。新生成图片和视频位于工作区 `outputs/Insight/images` 与 `videos`。不替换历史原文、模型 ID、供应商名称或原生技术命令。安装、在线资源和更新步骤见 [RELEASE.md](RELEASE.md)，智能体来源汇总见 [UPSTREAM-SOURCES.md](UPSTREAM-SOURCES.md)。

## 界面与阅读

- 智能体按分类以四列卡片展示，支持按名称、简介和分类搜索；简介完整显示，当前助手有明确文字标记。宽屏并排显示，内容宽度不足 1680px 时使用可关闭的四列抽屉，支持 Escape 关闭和键盘焦点循环，选择后回到输入框。
- 正文为 16px，回复完成后展示 Markdown 标题、列表、表格、引用和代码。横向较宽的表格可独立滚动。复制按钮保留原始 Markdown；生成的 HTML 作为文字显示，不自动加载回复中的外部图片。
- 流式阶段仍按帧追加文本，保留选区与阅读位置。超过 100,000 字符或结束时仍有文字选区的单条消息保持纯文本，避免长文本解析卡顿或破坏选区。思考与工具执行结果可展开查看；工具结果预览限前 4,000 字符，原生会话保留完整结果。
- 会话历史沿原生 session 的当前分支从头展示，包括上下文压缩前的消息；不会把其他分支混入当前对话。压缩处显示分隔提示，模型仍使用压缩后的上下文，不把完整历史重新发送给模型。
- 设置按账户、对话、图片、视频分区。常用图片参数直接显示，张数与背景在「更多选项」中展开；关闭和保存按钮固定可达。参数值和服务商请求合同不因界面布局改变。

更新界面后重开桌面窗口一次。Pi 的 `/reload` 仅重载代理资源，不刷新 Electron 界面代码。

## 运行

0.2.0 推荐使用 [Windows 免安装压缩包](PORTABLE.md)：完整解压后双击「学术派」快捷方式。基础能力随包提供，大型智能体首次点击时下载；移动程序、更换版本保留原账户、会话和资源。

开发者在仓库根目录进入桌面目录执行：

```powershell
cd desktop
npm install --ignore-scripts
npm run start
```

旧安装版仍可运行 `Insight-Setup-<版本>-x64.exe`，并通过 Windows「应用和功能」卸载。免安装版退出后删除解压目录即可移除程序，个人数据不随程序删除。仓库中的 CMD 和绝对路径快捷方式仅为开发入口；发布 ZIP 的快捷方式使用相对路径。主程序已隐藏默认开发菜单栏。

标识原图原样保存为 `src/icons/xueshupai-source.png`（1254×1254）；`xueshupai.png` 为等比例缩小的 512×512 版本，Windows ICO 含从原图分别缩小的 16 至 256 像素帧。保留原图底色、构图与比例，不抠图、不放大；高对比度模式仍显示原彩色徽章。需要重新生成资产和本机快捷方式时，运行 `desktop/node_modules/electron/dist/electron.exe desktop/scripts/brand-assets.cjs --shortcut`（仓库根目录）；不请求模型或联网。快捷方式包含本机绝对路径，不进入 Git。

客户端使用原生 RPC 引擎；开发模式从 `.pi-install` 加载，安装版从程序自带的 `resources/product/runtime` 加载，Node/npm 也随安装版提供。默认连接 `jarodfund / gpt-5.6-sol`，模型和工作区可在界面右上角或“设置”里切换。用户不需要准备开发运行时。

## 账户与 Key

首次没有 Key 时会自动打开设置，填入自己的 JarodFund API Key，点击“验证并连接”。客户端验证 Key 并获取该账户的可用文本模型，失败时保留原账户。

- 默认勾选“记住 Key”：使用 Windows 账户加密保存，重启客户端后自动使用，不必再次输入。
- 不勾选：Key 只在本次客户端进程有效，关闭后需要重新输入，并移除之前记住的 Key。
- 切换：设置中填入新 Key，点击“验证并更换 Key”。
- 退出：点击“退出当前 Key”，清除内存和本地保存的凭据，关闭当前对话视图；已保存的 Pi 会话文件仍保留。退出后不会自动加载原环境变量 Key，重新启动也保持退出状态。

首次可读取本机 `JARODFUND_API_KEY`，不使用其他服务的 `OPENAI_API_KEY`。退出只影响桌面端，不修改 Windows 环境变量。所有会话共享账户；需先停止或等待所有会话的任务结束，才能切换账户。切换或退出会同步其他会话的运行时，不会让旧进程继续使用旧 Key。

加密凭据位于 `%APPDATA%\Insight\jarodfund-key.enc`；普通设置文件不包含 Key，登录框也不会回填已保存的 Key。

## 工作区和历史对话

- 左侧“工作区”旁的 `+` 添加文件夹，没有固定数量上限；同一目录不会重复添加。
- 点击工作区切换，恢复该工作区上次打开的对话，同时切换 Pi 工具实际操作的目录。
- “全部会话”展示所有工作区的历史，按最后消息时间排序，标题默认取第一条消息，每项标注所属工作区。可搜索标题或工作区路径，通过行末菜单重命名；点击会话自动选中其工作区，并恢复原上下文继续聊。
- 工作区列表、对话名称、上次打开的对话和本版产生的任务用时保存在 `%APPDATA%\Insight\desktop-library.json`。重启后自动恢复。旧版没有记录的任务用时不会凭空补算。
- 已有桌面端会话自动发现；开发模式还发现当前 Pi 全局目录，安装版不导入其他客户端配置。对话正文仍保存在原生会话文件中，不按 API Key 分隔；同一 Windows 用户切换 Key 后仍能访问本机历史。
- 未选中的工作区可通过行末菜单移出列表；该工作区有运行中的任务时需先结束。只移除快捷入口，不删除目录或会话文件，历史仍显示；打开原会话会恢复工作区入口。
- 同一窗口可同时运行多个会话。任务运行时，新建对话、打开其他历史/工作区、选择另一智能体都在当前窗口切换，原会话继续在后台运行；切回已有会话直接显示缓存视图，不重启进程或重发提示。新增并行任务优先复用已空闲的后台进程，避免每次导航都多开进程。
- 左侧「在新窗口中开始」仍可主动打开独立窗口。同一会话只允许一个运行实例；如果已在另一独立窗口中打开，会聚焦已有窗口，避免同时写入同一份历史。
- 每个会话独立保留消息、计时、生图/视频连接与权限审批，共享历史目录和账户；已缓存视图还保留阅读位置。草稿和附件跟随会话，即使后台进程被复用也可恢复；未发送的新会话草稿也显示在列表中。草稿不跨应用重启保存。
- 可在任务运行时输入下一条草稿、添加文件、搜索历史或复制消息。左侧标注运行中、等待批准、等待回答或失败，审批只在所属会话处理。当前会话的模型/运行配置在任务结束后修改；停止只影响当前会话，关闭窗口会先确认并停止该窗口全部前后台任务。不同会话仍可操作同一磁盘文件，并行编辑时需要自行协调工作对象。

## 运行中追加消息

任务进行时，Enter 或「追加」可继续发送普通消息、文件引用和图片，不需要先停止。Shift+Enter 仍用于换行。输入框旁可选择：

- 补充当前任务（默认）：在当前模型回复及工具调用结束后的处理节点交给 Pi，用于补充材料或纠正方向；不会强行打断正在执行的命令或生图请求。
- 完成后处理：等待当前任务不再需要工具或补充消息后，自动处理下一项。

输入框上方展示原生 Pi 的待处理队列；实际交给模型时，消息才进入会话正文，不重复展示。追加消息沿用当前任务计时和权限模式。「取回待发送」把尚未处理的内容放回输入框；点击停止也会取回这些内容，保留已有草稿，图片和文件保留为本地路径引用。取回多条会合并为一段可编辑文本。桌面窗口仍打开时，如果 Pi 子进程断开，缓存的待处理内容也会回到输入框，恢复连接不会自动重发。已开始处理的消息不能取回；待处理队列和未发送草稿不跨应用重启保存，关闭客户端前请取回并复制需要保留的内容。运行中斜杠命令仍需等待任务结束。

交互参考 [Codex 的引导与排队](https://learn.chatgpt.com/docs/prompting#steering-and-queuing) 和 [Claude Code 的运行中消息队列](https://code.claude.com/docs/en/interactive-mode#queue-messages-while-claude-works)，实际调度由 Pi 原生消息队列执行。

## 权限管理

「权限管理」位于顶部「对话模型」左侧。新安装默认「请求批准」，选择按会话持久保存，并作为以后新会话的默认值；各会话可以使用不同模式。切换模式影响后续工具调用，不撤销已经执行的操作，尚未处理的审批会被取消。

| 模式 | 自动执行 | 需要批准 |
| --- | --- | --- |
| 只读 | 读取工作区普通文件 | 写文件、工作区外读取、联网、命令与扩展工具 |
| 请求批准 | 读写工作区普通文件 | 工作区外文件、联网、命令与未知扩展工具 |
| 智能批准 | 普通读取、工作区内写入、公开网页搜索与已识别的 HTTPS 抓取 | 敏感文件、工作区外写入、任意脚本/命令、未知工具及生图视频等外部付费操作 |
| 完全访问 | 所有工具调用，包括网络和工作区外写入 | 不弹出工具审批 |

审批卡片显示工具、工作区、原因和参数，可「允许这一次」或「拒绝」。批准不被缓存为后续操作的通行证；停止任务、关闭窗口或权限服务断开时不继续放行。文件范围解析已有父目录和 Windows junction，防止简单的相对路径/目录链接越界。聊天模型请求、模型目录查询、会话保存及用户直接点击的文件打开/复制不属于模型工具审批。

这是 Pi 工具执行前的审批层，不是 Windows 操作系统沙箱。无法可靠限定任意命令的写入和联网范围，所以非「完全访问」模式会保守确认命令；批准脚本、子代理或扩展工具包含其内部操作。已安装扩展自身的启动代码仍是受信任的本地程序，不能用该功能运行不可信插件。模式说明不会声称已经实现 Codex 的系统级隔离。敏感文件识别与智能批准采用保守规则，不是安全证明。

## 专用智能体与本地文件

右侧「智能体」包含「工作常用」「通用科研工作台」「大师思维框架」「自媒体创作」四个专区、十八个内置入口，另有「我的智能体」个人区域。工作常用四个入口，通用科研工作台八个，大师思维框架四个，自媒体创作两个。点击卡片选择，在当前输入框描述任务即可使用；不会立即发送消息或清空草稿。输入框顶部显示当前助手，点击旁边的 × 切回普通助手。选择跟随原生会话并持久保存，新对话默认普通助手。窄窗口通过右上角按钮打开侧栏。

- PPT Master：保留原技能、模板、原生对象导出脚本与完整性检查。
- Codex PPT：保留大纲、样张、风格库、图片生成与组装流程；适配桌面 `image_gen`，使用当前生图设置。
- OpenResearch：内置 Windows `orx 0.2.4` 和研究/实验技能；本地工作不需要另一个登录，托管算力与账户服务仍需对应账号。
- Feynman：内置论文、PDF、代码核验技能与提示工作流，复用 Pi 工具和 OpenResearch 论文检索；未嵌入 Feynman 独立终端和全部外部科学服务。
- Academic Research Skills：原始研究、写作、审稿及配套资源。Claude 专属 hooks 不在 Pi 运行；缺少隔离子代理时必须披露串行角色审查。
- PaperQA：实际调用 Python `Docs` 检索与问答，默认本地 sparse 关键词检索，无需单独 embedding Key。证据摘要与回答使用当前 JarodFund 聊天模型；不是离线模型。结果写入工作区 `outputs/paperqa/`。
- 书籍转技能：内置 book-to-skill 原始技能、文档提取器和安全扫描器；提取本地 PDF、EPUB、DOCX、HTML、TXT/Markdown，沿用当前会话模型提炼框架、原则、章节索引与速查表，默认输出到工作区 `outputs/book-skills/`。提取本地执行，模型分析的文本仍会发送给当前服务商。生成前确认内容规模；不自动写入其他客户端技能目录、提交或发布仓库。扫描件 OCR、技术排版 Docling 和 MOBI/AZW 的 Calibre 未预装，使用时说明限制。生成的技能默认只交付文件；明确要求安装时，经扫描后放入个人技能安装目录，再点击「刷新智能体」。
- 搜全网：Agent Reach 1.5.0 的平台路由、参考文档与 CLI；Exa 语义搜索经本地 mcporter 0.7.3 调用，公开搜索无需额外 Key，网页/RSS 可用。搜索配置关闭其他编辑器导入。站内专有工具、浏览器扩展和需登录的平台不是自动全部开通，以具体任务的实际返回为准。
- 下全网：yt-dlp 2026.8.19（含 EJS）下载视频、音频及字幕，使用随附 Node。默认单链接、断点续传、不覆盖，文件保存到工作区 `outputs/downloads/`，完成后核对真实文件、时长和画质。音视频合并/转码使用资源包随附的 FFmpeg；开发模式也可使用 PATH 中的 FFmpeg。平台支持范围和登录限制以 yt-dlp 实际结果为准。
- 标准化实验日志记录：从本机 `nature-experiment-log` 原样内置技能、三份实验示例和三份模板；使用当前会话接收材料，默认在工作区 `outputs/experiment-logs/` 下建立 YAML frontmatter 日志、材料索引和异常记录。可指定 Obsidian vault，无需先配置飞书；缺失实验字段保留待确认，不复制示例中的虚构数据。图片读取取决于当前模型，音视频可归档；音频转录需实际可用的转录工具或用户提供字幕/文字，FFmpeg 抽帧不等于完整视频理解。未新增自动转录服务。
- 多源交叉验证：从本机 `nature-ref-verifier` 内置完整技能与常见错误参考，复用 Pi 的搜索/网页/HTTP 工具逐字段核查参考文献，默认报告输出到 `outputs/reference-verification/`。必须附实际证据、区分单源结果与多源一致，不能从 DOI 数字猜年份。Zotero、CNKI 等专用连接依环境配置，无访问能力时标记未验证；不自动修改原稿或文献库。
- 神级拷问：内置 Matt Pocock 的 `grill-me` 入口及实际 `grilling` 技能，用 Pi 原生 `read` 加载完整流程，不依赖其他客户端的 `Skill` 工具。围绕需求建立决策树，分轮提问、给出建议、等待回答，最终整理需求并请用户确认后再执行。可随时要求暂停或结束，沿用当前会话和模型，无新增依赖或后台服务。

- 大师思维框架：仅保留查理·芒格、纳瓦尔、马斯克、费曼。原样内置完整技能、参考资料和许可证，位于 `specialists/perspectives/`，文件哈希见 `snapshot.json`；原八人源码快照保留作溯源，另外四位不再展示或可选。只读取选中的框架，不依赖 Codex 或 Python，不另开模型进程。使用当前聊天模型，保留原技能的首次身份说明、事实核查和退出角色规则；这些是公开资料提炼的模拟视角，不是本人意见。这里的费曼与科研区的 Feynman 项目是两个独立入口。
- 一站式自媒体创作：Easel 的热点、策划、图文/视频、发布与复盘技能接入当前 Pi。独立 Python 3.13 环境包含浏览器截图、图片/图表、配音、字幕和剪辑所需组件；AI 图片/视频复用当前 JarodFund 设置。发布需登录目标平台并明确授权，不默认具备全部平台账户或可选云服务，不启动 OpenClaw 网关。
- 口播/课件神器：Hyperframes 0.8.58 原始技能与固定版本 CLI，使用 HTML/CSS 在本机渲染视频并保留源码。Chromium 显式安装，使用现有 FFmpeg；不默认调用 HeyGen 云渲染、数字人或声音克隆服务。

「我的智能体」提供安装说明、「打开安装目录」和「刷新智能体」。把含 `SKILL.md` 的完整技能文件夹放入 `%APPDATA%\Insight\agent\skills` 后刷新，无需重启，可跨工作区选择使用。技能名称与简介来自实际加载的技能；已加载的技能包和原生共享技能目录也会显示，纯工具扩展不会生成卡片。不单独扫描其他客户端目录。刷新不调用模型、不清空草稿；移除技能后再次刷新会撤销失效的选择。

## 截图与会话生图

- 粘贴截图的便捷功能保留：无磁盘路径的 PNG、JPEG、WebP 截图先在本地保存校验，每条消息最多 4 张，每张 20 MB。选择或拖入磁盘图片则按上面的文件路径规则处理。
- 粘贴截图通过 Pi 原生 `prompt.images` 交给支持图片的聊天模型；不支持图片的模型会明确提示，不会静默丢弃。JarodFund 目录未声明输入类型时，为已知 GPT、Claude、Gemini 多模态系列补上图片能力；已有显式 `input` 配置优先。服务商是否实际支持仍取决于对应路由。
- 设置里的「会话生图模型」读取当前 Key 的模型列表，仅展示下表已按 JarodFund 2026-09-17 文档适配的模型。聊天模型和生图模型独立；直接说「生成一张……」或上传参考图后说「把背景换成……」，由内置工具调用，不需要斜杠命令或另填 Key。
- 生图参数随模型变化，每个模型分别记住设置。只改生图模型或参数时直接保存，不重启 Pi、不新建对话，当前会话下次生图即生效；已在生成的请求需先完成或停止。`image_settings` 让模型读取最新选项；`image_gen` 未填写的参数使用保存值，对话中显式指定的参数仅覆盖本次请求。
- 生图模型严格以用户设置为准：工具参数不能覆盖模型选择，聊天模型报错后不能擅自切换到其他图片模型。需要换模型时在设置中选择；不会自动回退到另一条生图通道。
- 工具可选字段允许 `null`；未填写、`null` 或空白参数不覆盖已保存的选项。针对工具调用把跨模型字段一并填满的情况，适配器只发送所选模型支持的参数，并在结果中注明忽略的字段和实际参数。不自动更换模型或尺寸；无效尺寸、超额张数、过多参考图和未知字段仍在请求前拦截。
- GPT 与 Grok 的文生图走 `/images/generations`，参考图编辑走 JSON `/images/edits`，分别使用 `images[].image_url` 和单图 `image.url` / 多图 `images[].url`；不会因目录中通用的 `openai` 标签把 GPT 2.5 误送到 Chat。Gemini 使用 `/chat/completions`，尺寸位于 `extra_body.google.image_config`，支持 Markdown、结构化图片和 `inlineData` 返回。参考图使用上传附件或以前生成的本地文件，编码为实际格式的 Data URL；每次连续修改均显式传入基础图。
- 生成结果原样保存在当前工作区 `outputs/Insight/images/`，保存后重新读取、解码并核对实际像素，不放大图片或把预览尺寸当作原生尺寸。会话内显示预览、尺寸、绝对路径，支持点击大图、「本地打开」和「复制」。本地打开使用系统默认看图软件；复制同时提供原尺寸图片内容与原文件，供编辑器、聊天应用或资源管理器粘贴，具体接受哪种格式由目标应用决定。不再弹出另存为对话框。图片内容随原生会话保存，重启后可回放；附件原文件位于桌面 agent 的 `attachments/`。
- 生图最长等待 960 秒，HTTP 连接和本机工具桥接都允许长请求。生成 POST 不自动重放，避免超时后重复计费；结果下载或文件验证最多额外尝试两次。错误保留 HTTP 状态、脱敏后的原因和请求 ID；纯文字、空响应或无法解码的文件不算成功。多图中部分失败时保留其他成功图片，逐项报告失败，不重新生成整批。
- 生成文件和连续编辑参考文件上限 48 MB，JSON 响应上限 256 MB，上传仍为每张 20 MB。最多保存 10 张结果，所有输出均重新读取并解码。显示实际尺寸，GPT 返回尺寸与请求不一致时提示；不会把 `2160x2160` 标成原生 `4096x4096`。透明背景是请求选项，不保证服务商实际返回透明通道。
- 7 个模型的请求格式、参数边界、十图输出、部分失败、设置续聊和历史回放使用本地模拟服务验证，没有调用真实付费生图模型。具体权限、额度、成功率和画质以 JarodFund 返回为准。

| 模型 | 单次输出 / 参考图上限 | 设置 |
| --- | --- | --- |
| `gpt-image-2` | 4 / 4 | 15 个固定像素尺寸；默认 1024×1024，不传质量和背景 |
| `gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` | 1 / 1 | 自动或自定义像素、6 档画质、自动/不透明/透明背景 |
| `gemini-3-pro-image-preview`、`gemini-3.1-flash-image-preview` | 1 / 2 | 5 种比例，1K/2K/4K；默认 1:1、2K |
| `grok-imagine-image`、`grok-imagine-image-quality` | 10 / 3 | 14 种比例，1k/2k；默认 1:1、1k；高画质由模型名决定 |

GPT 2.5 自定义宽高须是 16 的倍数、各不超过 3840，宽高比在 1:3 至 3:1，总像素在 655360 至 8294400。面积超过 2560×1440 时提示实验性分辨率（包括 2048×2048）。不支持蒙版；所选模型的无效参数值或超限参考图数量在发送前报错，不静默丢图。

## 会话视频生成

设置中的「会话视频模型」与聊天、生图模型独立，读取当前 Key 的模型权限。选择模型、时长、比例和分辨率后，直接在对话中说「生成一段……视频」即可使用内置 `video_settings` / `video_gen`，无需斜杠命令或另一枚 Key。保存的视频设置在当前会话下一次请求生效，不重启 Pi；工具不能擅自切换模型。

| 模型 | 时长 | 比例字段 | 分辨率 |
| --- | --- | --- | --- |
| `grok-imagine-video-1.5` | 已验证的 15 秒 | `aspect_ratio`，5 种比例 | 省略，由服务商决定 |
| `seedance2.5` | 4–30 秒整数 | `ratio`，6 种比例 | `480p` / `720p` |
| `omni-flash` | 4 / 6 / 8 / 10 秒 | `ratio`，5 种比例 | 已验证的 `720p` |
| `minimax-h3` | 4–15 秒整数 | `ratio`，6 种比例 | `768p` / `2k` |

本版按用户提供的 JarodFund 2026-09-18 文档接入纯文生视频；首帧、参考素材、视频编辑尚未接入，不会把本地附件路径当作公网素材地址。未填写的选项沿用该模型保存值；聊天中显式指定的有效选项可覆盖本次请求。不支持的时长和分辨率会在提交前报错。

通过 `POST /v1/videos` 创建任务，立即持久保存公开任务 ID，然后每 5 秒查询一次 `/v1/videos/{id}`。只有 `completed` 才下载 `/content`，查询和下载均使用后端保存的 Key；跨站下载重定向不携带 Key。不指定渠道、上游地址或供应商。提交不自动重放；查询和下载临时故障最多额外尝试两次。

会话卡片显示排队、生成、下载、完成或失败。最长本地等待 30 分钟；点击停止或关闭应用只停止本地等待，不取消远端任务。任务记录保存在 `%APPDATA%\Insight\video-tasks`，按账户和工作区隔离且不保存 Key。重开原会话后可点击「继续获取」，使用原 ID、模型和参数查询，不再提交视频生成。失败的远端任务不会被当作成功。

成功下载的 MP4 原样保存在工作区 `outputs/Insight/videos/`，上限 512 MB。完成前检查确切文件存在、非空、写入长度、MP4 容器，以及 Electron 能否解码首帧、读取实际时长和像素。会话中直接播放、显示实际参数和绝对路径；「本地打开」使用系统默认播放器，「复制」将原 MP4 作为文件放入剪贴板，可粘贴到支持文件的应用或资源管理器。复制不是路径文字，也不读取整个视频到剪贴板内存。历史记录保留这两个操作；文件缺失、打开或复制失败会明确提示，不重新生成或自动下载；需要恢复时可继续获取原任务。

使用本地模拟服务验证请求合同和完整桌面流程，没有提交真实付费视频任务。模型权限、可用性和实际输出以 JarodFund 为准。

## 任务恢复和计时

左下角 JarodFund 状态卡提供「恢复连接」。本地 Pi 进程掉线或响应超时时，可直接重连，不必关闭窗口或重新输入已保存的 Key；工作区、原对话、所选智能体、输入草稿和附件保留。任务运行时需先停止或等待结束，重连不会重新发送之前的任务或生成请求。

启动握手单独等待最多 180 秒，期间显示初始化进度；临时启动失败会自动重试一次，仍失败则保留可手动恢复的入口。普通控制请求仍为 30 秒超时。本地启动故障显示具体原因，不再一律提示「请检查配置」；「会话已连接」表示本地 Pi 就绪，不是服务商健康或额度保证。

网络中断、服务繁忙、限流等临时错误由 Pi 自动重试，保持任务进行中，不弹出中间错误。每次连续失败最多重试 10 次，等待时间从 2 秒逐步增加，上限 30 秒；单次请求和流空闲超时为 60 秒。重试沿用当前上下文，不重新提交用户任务或重放已经完成的工具步骤。无效 Key、权限、额度等永久错误，以及重试耗尽，会显示最终失败。

计时从提交任务开始，包含工具执行和等待重试的时间。任务完成、停止或失败后计时冻结，对话内显示本次用时。可以在后台等待重试时点击“停止”。

学术派的代理配置独立位于 `%APPDATA%\Insight\agent`；CLI 的全局重试设置不受影响。

## 交互响应

- 切换已打开的并行会话直接显示其缓存视图；空闲时打开其他历史/工作区通过 Pi 原生 `switch_session` 复用后台进程。新增并行会话仅在没有可复用进程时初始化运行时；新建空工作区仅生成原生会话头，不发送模型请求。切换取消时保留当前对话，切换出错时恢复原工作目录和会话。
- 安装生态扩展后，切换工作区复用受版本限制的安装包模块，每次仍创建新的扩展实例、读取项目资源和扩展配置；避免重复触发同一会话的扩展启动回调。本地扩展保留原有工作目录隔离，`/reload` 清空模块工厂缓存，子代理的加载模式单独隔离。
- 点击导航立即显示顶部进度条，并在后台真正就绪前防止重复操作。更换账户或在设置中修改聊天运行配置会重新启动 Pi；仅保存生图或视频设置不重启。首次启动需要加载运行时。
- 历史索引保存在磁盘并由后台线程维护，按文件大小和时间判断变化，仅重新解析变化的 JSONL，不把整段正文或 Base64 传回主窗口。短期缓存 5 秒，任务结束时失效；列表每批显示 100 条，搜索仍覆盖全部历史。完整会话每 60 条消息让出一次界面线程，旧消息仍可滚动查看。
- 流式文本按动画帧合并、追加文本节点。向上滚轮（包括底部附近的小幅滚动）、拖动滚动条、按 PageUp/Home 或选中文字时暂停自动跟随；「回到最新消息」恢复跟随。消息区关闭浏览器的自动滚动锚定，正文重新排版也保留阅读位置。每条消息右上角的复制按钮在本机复制，并提示成功或失败。图标为随应用打包的 Lucide 0.468.0 Copy，许可见 `src/icons/LICENSE`，无需联网加载。
- 输入框支持 Pi 的常用斜杠命令：`/reload`（无重启重新加载扩展、技能、提示和上下文）、`/new`、`/compact`、`/model`、`/thinking`、`/name`、`/session`、`/copy`、`/commands` 和 `/settings`。桌面端不执行会退出客户端或打开交互式选择器的 CLI 命令；未知命令会给出明确提示，不会静默丢失。
- 输入 `/` 显示可用命令，包括当前工作区加载的扩展命令、提示模板及技能；上下键选择，Tab 补全，Escape 关闭。完整命令按 Enter 执行，Shift+Enter 换行，中文输入法确认候选词不会发送。
- 本地控制命令不发给模型，也不生成虚假的用户消息或任务计时。提示模板和技能命令仍交由 Pi 原生展开后执行；`/compact` 会调用模型并记录用时。

本机隔离配置、真实 Pi 进程、不调用模型的测量中：未装扩展时，原先约 2.3–2.7 秒的进程重启式导航已降到约 0.1–0.2 秒。本次装齐生态组件后，工作区切换从约 1.83 秒降到约 0.20 秒，连续五次为 0.17–0.23 秒；新建对话从约 0.29 秒降到约 0.22 秒。首次启动仍约 4.6 秒，主动 `/reload` 仍约 1.5 秒。实际耗时受扩展、历史体积和磁盘影响，不代表所有机器的保证值。

## Windows 工具与 CLI 的边界

桌面端通过原生 Pi RPC 运行，不是另写的一套文件工具。Windows 默认启用 `read`、`bash`、`powershell`、`edit`、`write`、`grep`、`find`、`ls`；已有 `defaultTools` 配置优先，不强行覆盖用户的工具选择。

Bash 路径优先使用桌面端 `agent/settings.json` 的 `shellPath`；开发模式还可沿用 CLI 全局配置，再从 `GIT_BASH_PATH`、Git 默认安装位置和 PATH 查找。Git 安装在自定义目录也可以使用；没有安装 Bash 时，PowerShell 仍是独立工具。首次更新桌面程序后需重开客户端一次，后续修改桌面配置可执行 `/reload`。

- 会话正文使用 Pi 原生 JSONL，历史列表不是另一份独立聊天记录；工作区 `AGENTS.md`、项目 `.pi` 资源和桌面 agent 目录内的扩展、技能、提示由 Pi 原生加载。
- 桌面 agent 目录独立于 CLI 全局目录。仅开发模式可沿用 CLI 的模型目录、shell 路径和工具选择；安装版不导入 CLI 全局配置。扩展、技能、主题和包在桌面 agent 目录或项目中配置，内置组件由资源包管理。
- 目前没有 `/tree`、`/fork`、`/clone`、导入导出及包管理的专用 UI，也没有照搬 TUI 快捷键、组件和主题。历史列表可继续已有会话，但不等于 CLI 的完整会话树界面。
- 扩展普通命令和通知可用；需要选择、确认、输入或编辑对话框的扩展操作会提示并取消，避免后台一直等待。终端专用自定义组件尚不支持。

当前安装的 Jiti 2.7.0 即使关闭模块缓存，也会将部分 JavaScript 文件交给 Node 原生缓存，导致 `/reload` 后仍执行旧代码。桌面启动时应用严格匹配版本与源码的兼容修补，仅让 `node_modules` 外的本地扩展及辅助文件绕过缓存，SDK 和安装包依赖保持原生加载。原文件保留在 Jiti 的 `dist/jiti.cjs.insight-original`；版本或源码不匹配时拒绝修补并报告错误。升级运行时后需要复核该修补，修改 `node_modules` 中的扩展或依赖仍需重启。此修补位于本项目安装的运行时，共用该运行时的 CLI 也会受到影响。

导航修补同样严格限定 Pi 0.85.1 的源码，原始 `loader.js` 和 `rpc-mode.js` 旁保留 `.insight-original` 备份。跨工作区模块复用仅由桌面子进程开启，仅包含当前验证过的四个固定版本扩展；其他包及升级后的扩展使用原生缓存规则。重复会话绑定修复作用于共用此运行时的 RPC 客户端。此次更新需要重开桌面客户端一次，已有后台进程不能通过 `/reload` 更新 RPC 本身。

## 已安装的生态组件

本机安装记录和使用边界见 [ECOSYSTEM.md](ECOSYSTEM.md)。开发模式使用独立 agent 目录中的 npm 安装；安装版下载 `ecosystem` 资源包后加载固定版本的扩展，不复制开发者账户配置。

当前桌面版还内置了 `pi-lens`（代码诊断与格式检查）、`rpiv-todo`（待办工具和 `/todos`）、`rpiv-ask-user-question`（结构化提问工具）以及 `pi-background-tasks`（后台任务工具）。这四个包已固定版本并由桌面端自动加载，不需要手动执行 `/reload` 选择。结构化提问的选择和文字输入会显示为桌面弹窗；需要终端、自定义 TUI 或任意确认框的扩展界面仍会取消，避免后台任务无限等待。

## 结构

- `src/main.cjs`：Electron 主进程，管理系统窗口及其中缓存的会话视图；每个并行会话有独立 Pi RPC 和任务，按发送视图分发 IPC，空闲运行时可复用，共享账户/历史及设置持久化。
- `src/permissions.cjs` / `src/permission-bridge.cjs` / `src/permission-extension.js`：四档权限策略、一次性审批、鉴权的本机服务与原生工具执行前拦截。
- `src/rpc.cjs` / `src/task.cjs`：RPC 传输和整项任务状态、计时。
- `src/library.cjs`：多工作区列表、Pi 原生历史发现和桌面对话元数据。
- `src/credentials.cjs` / `src/agent-config.cjs`：凭据管理、模型目录和重试配置。
- `src/slash-commands.cjs` / `src/runtime-patches.cjs`：命令目录与受版本保护的本地扩展重载修补。
- `src/navigation-patches.cjs`：受版本保护的导航修补、已安装扩展的模块复用名单。
- `src/runtime-env.cjs`：仅为 Pi 子进程添加随附 Node 和扩展命令目录，隔离 MCP 配置来源。
- `src/images.cjs` / `src/image-bridge.cjs` / `src/image-extension.js`：图片校验、服务商接口和 Pi 原生生图工具；仅在桌面启动时加载，使用本机随机令牌桥接。
- `src/image-models.cjs`：7 个模型的独立请求合同、尺寸和数量校验。`src/image-http.cjs`：16 分钟请求等待；将本机已有的 Undici 7.29.1 固定为直接依赖，无版本升级。已核对其[发布说明](https://github.com/nodejs/undici/releases/tag/v7.29.1)，使用普通 Agent，不启用重试、缓存或解压拦截器，避免这些机制改变生图 POST 语义。
- `src/video-models.cjs` / `src/videos.cjs`：4 个视频请求合同、持久任务 ID、轮询恢复和流式 MP4 下载。`video-extension.js` / `video-bridge.cjs`：Pi 工具与本机鉴权桥接。`video-verifier.cjs`：使用 Electron 校验 MP4 和首帧，运行时不依赖额外安装 FFmpeg。
- `src/preload.cjs`：安全的 IPC 白名单桥接。
- `src/media-actions.cjs`：本地图片/视频校验、系统默认打开和原生图片/文件剪贴板操作。使用 Electron 44 的异步 `ClipboardItem`；[文件格式映射](https://www.electronjs.org/docs/latest/api/clipboard-item#files-the-texturi-list-mime-type)由 Electron 处理，无需额外进程。
- `src/specialists.cjs` / `src/specialist-extension.js`：智能体目录、按需注入指导及 PaperQA 工具。`src/local-files.cjs`：仅包含元数据的路径附件。
- `src/index.html` / `src/styles.css`：包豪斯界面。
- `src/renderer.js`：流式消息、模型、推理强度和新会话交互。
- `src/message-format.js`：本地 Marked 18.0.13 解析与 DOMPurify 3.4.15 清理，保留原文复制；禁用回复中的脚本、样式和远程图片自动加载。
