学术派把 Pi 的代理引擎、多模型接入和专业技能整合进中文桌面界面。放入材料，说明目标，让 AI 读取文件、调用工具、分工处理，并把成果保存到工作区。既可以从一个简单问题开始，也可以围绕同一份材料持续做研究、写作、演示与创作。

> **发布状态：** GitHub 首次发布分批准备：先提供图文介绍与文档，产品源码及正式下载尚未发布。Windows 0.2.3 已完成本地运行验收；0.2.4 已重新打包，验收进行中。Linux 与 macOS 为待实机验收的候选包。需要自己的 JarodFund Key，模型调用及部分外部服务可能产生费用。详见[下载与平台状态](docs/DOWNLOADS.md)。

## 专长就位，选一个就能开始

四列卡片，按名称、用途或分类搜索。选择卡片后，直接在当前对话描述任务；不需要记住每个项目的命令。大型依赖首次使用时按需下载，共享资源可复用。

| 专区 | 内置智能体 |
| :--- | :--- |
| **工作常用** | 一键制作原生 PPTX · 图片风格精美 PPT · 搜全网 · 下全网 |
| **通用科研工作台** | 读论文、管实验、记过程 · 搜 arXiv、问 PDF、核对论文代码 · 写综述 / 初稿 / 模拟审稿 · 本地文献高准确问答 · 书籍转技能 · 标准化实验日志记录 · 多源交叉验证 · 神级拷问 |
| **大师思维框架** | 查理·芒格 · 纳瓦尔 · 马斯克 · 费曼 |
| **自媒体创作** | 一站式自媒体创作 · 口播 / 课件神器 |
| **我的智能体** | 安装自己的完整技能文件夹，刷新后显示为个人卡片 |

人物入口是基于公开资料提炼的模拟分析框架，不代表本人观点。“搜全网”“下全网”等为入口名称，不保证覆盖所有站点。科研结果仍需核对原文与原始数据。

## 为持续工作设计

- **会话不中断：**切换到其他会话，原任务继续进行；需要补充材料时，可选择“补充当前任务”或“完成后处理”。
- **工作区不混淆：**统一展示历史会话，打开后回到对应工作目录；草稿、阅读位置与审批按会话区分。
- **材料少搬运：**多选或拖入本地文件时先引用路径，由工具根据任务读取；生成成果保存为本地文件。
- **过程可查看：**Markdown、表格、代码、思考与工具结果各有适合的展示方式，支持复制。
- **界面有秩序：**包豪斯几何构成、克制的色彩、浅色与深色主题；宽屏并排，窄屏收起智能体面板。

## 为什么选择 Pi 作为底座

**精简核心，能力按需组合。** 学术派沿用 Pi 的模型交互、工具执行、会话和上下文管理，让专业工作流通过扩展与技能接入。技能摘要供模型发现，完整内容按任务读取，避免将所有工作流正文常驻上下文。

在这个底座上，学术派增加了：

| Pi 底座 | 学术派的产品整合 |
| :--- | :--- |
| 模型、工具与原生会话 | 中文桌面界面、多工作区、会话切换与历史管理 |
| 扩展与技能机制 | 预配置基础工具、专用智能体卡片与个人技能区域 |
| 原生消息队列 | 任务途中补充、排队与待处理消息提示 |
| 文件与命令执行 | 本地路径附件、四档工具审批、结果打开与复制 |
| 可扩展代理运行时 | JarodFund 多模型、图片 / 视频接口与参数适配 |

多智能体能力由集成的 **pi-subagents / council-mode** 等扩展提供；不是声称 Pi 核心原生自带全部编排能力。MCP 适配器已接入，但外部服务需自行配置。不同客户端的能力不完全等价，我们不以未经对照测试的“提示词更少”“模型一定更强”作为承诺。

## 从一件真实的工作开始

1. **选择系统包。** Windows x64、Linux x64、macOS Apple Silicon / Intel。完整解压，不要只移动启动文件。
2. **启动并连接。** Windows 双击 `学术派.exe`；Linux / macOS 在解压目录运行 `bash 启动学术派.sh`。设置中填写自己的 JarodFund Key。
3. **指定工作区与材料。** 添加工作文件夹，选择智能体，输入你想完成的目标。缺少的大型资源会在首次使用时提示下载。

> 阅读这些论文，整理研究问题、方法差异和不足，附上原文依据，再一起制作组会汇报 PPT。

> 检查这个项目，让子代理分别审查逻辑与测试，汇总问题后再按我的确认修改。

> 围绕这个知识点策划科普内容，制作配图与短视频素材，保存到当前工作区。

## 数据、权限与边界

**本地优先，不等于完全离线。** 会话、个人技能和成果保存在本机；提交给云端模型分析的文件内容仍可能发送给 JarodFund 或所配置的外部服务。选择文件时“只引用路径”不代表随后分析时内容不会离开本机。

权限可选**只读、请求批准、智能批准、完全访问**。这是工具执行前的应用层审批，**不是操作系统沙箱**；允许命令、脚本、扩展或子代理时，也授权了它们内部的操作。请只安装可信技能，谨慎处理敏感资料。

首次启动、资源下载、长会话及模型调用均可能需要等待。网站登录、平台发布和部分外部工具需要额外账户或授权；模型生成、引用准确性与平台可用性不作绝对保证。
